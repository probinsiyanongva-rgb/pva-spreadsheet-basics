Course orientation

Learn the spreadsheet basics so you can focus on the actual work.

Spreadsheets are common work tools for virtual assistants. The software may vary—Microsoft Excel, Google Sheets, LibreOffice Calc, or another comparable application—but the fundamental ideas are transferable.

This module is standalone and optional.

Learning Objectives

By the end of this module, you should be able to:

  1. Identify the basic parts of a spreadsheet.
  2. Understand workbook, worksheet, row, column, cell, and cell address.
  3. Navigate between worksheets and locate information.
  4. Enter, edit, clear, copy, and paste information.
  5. Undo an accidental change.
  6. Sort and filter a simple list.
  7. Recognize the difference between changing a view and changing underlying records.
  8. Work with common controls such as dropdowns and Yes/No fields.
  9. Recognize basic differences between text, numbers, and dates.
  10. Recognize areas that may be protected or not intended for editing.
  11. Complete a simple administrative spreadsheet task with reasonable accuracy.
  12. Use a few common keyboard shortcuts when useful.

Lesson 1

Understanding Spreadsheets

The basic building blocks
✓ Completed

A spreadsheet organizes information in a structured grid. Information is arranged using rows and columns, creating individual spaces called cells.

Customer IDCustomer NameStatusDate Added

C002Ben CruzPendingSeptember 4, 2026
C003Ana ReyesActiveSeptember 5, 2026

Workbook

A workbook is the spreadsheet file itself—the container for its worksheets.

Worksheet

A worksheet is an individual sheet inside the workbook, such as Customers, Orders, or Tasks.

Row

A row runs horizontally and is usually identified by a number. In a structured list, one row often represents one record.

Column

A column runs vertically and is usually identified by a letter. One column often contains one type of information.

Cell

A cell is one individual space where information can be entered or displayed.

Cell Address

A cell address normally combines the column letter and row number, such as A1, B3, or C5.

Header

A header describes the information contained in a column.

Table or Structured List

A structured list organizes related information into rows and columns. Each row represents a record and the headers describe the fields.

Learner Activity
  1. Look at any simple spreadsheet you have access to.
  2. Identify the workbook, a worksheet, a row, a column, a cell, a cell address, the headers, and the records.

Think about it: If a client asks, “Find the status of customer C002,” start with the relevant header and then locate the record.

Lesson 2

Navigating a Workbook

Find what you need before you edit
✓ Completed

A VA may receive a spreadsheet containing dozens, hundreds, or even thousands of records. You need to be comfortable locating information without randomly clicking through the file.

Opening a Workbook

Before editing, check that you have the correct file, the correct worksheet, the right type of information, and any instructions or notes.

Moving Between Worksheets

Click the appropriate worksheet tab. A workbook may contain Customers, Orders, Tasks, Notes, and other sheets.

Locating a Cell

For example, D7 means column D and row 7. Some applications also provide a name box or similar navigation field.

Finding Information

Most spreadsheet applications provide a Find function. On many Windows spreadsheet applications:

Ctrl + F → Find

The exact shortcut may vary by application or operating system. The menu command is always an alternative.

Scrolling Through a Dataset

Scroll vertically for more rows and horizontally for more columns. What you can currently see is only part of the worksheet.

Adjusting Column Width

If information is difficult to read because a column is too narrow, adjust the width using the method provided by your application.

Information Outside the Visible Area

“I can't see it” does not automatically mean “it isn't there.”
Check other worksheets, additional rows, additional columns, and the Find function.
Learner Activity
  1. Move to another worksheet.
  2. Select a specific cell.
  3. Find a particular piece of information.
  4. Scroll down through the records.
  5. Scroll horizontally to look for additional columns.
  6. Adjust one column so its contents are easier to read.

Shortcut practice: Try Ctrl + F if supported.

Lesson 3

Entering and Editing Information

Change only what the task requires
✓ Completed

A spreadsheet is useful because information can be changed. But changing information also creates a responsibility: change only what the task requires you to change.

Entering Data

Select the appropriate cell and enter the required value. Make sure you are in the intended row and column.

Editing a Cell

If an existing value needs correction, confirm the record, field, and requested change before editing.

Clearing a Cell

Clearing removes existing content. Only clear information when the task calls for it or when you are certain it is appropriate.

Copy and Paste

Copy and paste can save time. On many Windows spreadsheet applications:

Ctrl + C → Copy   Ctrl + V → Paste

Always check the destination before pasting because pasting can replace existing information.

Cut

Ctrl + X → Cut. Use Cut when information needs to be moved rather than copied.

Undo

If you accidentally delete, replace, or paste into the wrong cell:

Ctrl + Z → Undo

Stop and correct an accidental change before continuing.

Save

Ctrl + S → Save on many Windows applications. Cloud-based applications may save automatically.

Changing Existing Data vs. Adding New Data

Updating an existing record is different from creating a new record. If a client says “Add this customer,” do not replace an existing customer. If the client says “Update this customer's status,” do not create a duplicate.

Learner Activity
  1. Enter a new value.
  2. Edit an existing value.
  3. Copy a value.
  4. Clear a practice value.
  5. Make an intentional practice mistake.
  6. Use Undo to reverse it.
  7. Save if your application requires manual saving.

Try Ctrl + C, Ctrl + V, Ctrl + X, Ctrl + Z, and Ctrl + S. Menu commands are acceptable alternatives.

Lesson 4

Working With Lists and Tables

Sort and filter without losing the records
✓ Completed

Sorting a List

Sorting changes the order in which records are displayed. When sorting a structured list, use the application's proper sorting function so related information in each row remains together.

Filtering a List

Filtering temporarily displays only records that match a condition. The other records have not necessarily been deleted.

Clearing a Filter

After the task is complete, clear the filter when appropriate so the complete list is visible again.

Remember:
Sorting changes the order.
Filtering changes what is displayed.
Neither should be confused with deleting records.
Learner Activity
  1. Sort a practice list by one column.
  2. Observe how the records are reordered.
  3. Apply a filter to display one category.
  4. Review the filtered records.
  5. Clear the filter.
  6. Confirm that the complete list is visible again.

Lesson 5

Common Spreadsheet Controls

Recognize how information is meant to be entered
✓ Completed

Dropdown Fields

A dropdown provides a predefined list of choices. It helps keep information consistent. Select an available option rather than inventing a different format.

Checkboxes and Yes/No Controls

A checkbox or Yes/No control can represent a simple decision. The exact appearance varies by application. Read the associated header or instructions before changing it.

Basic Date Fields

Dates may appear in different formats, such as 09/28/2026, September 28, 2026, or 28-Sep-2026. Follow the format expected by the spreadsheet or client.

Text vs. Numbers

Some values look like numbers but are actually identifiers. For example, 00125 may be a customer ID rather than the number 125. Consider what the field represents before entering data.

Protected or Non-Editable Areas

Some cells or worksheets are protected intentionally. Do not try to bypass protection. Check instructions or use the intended input area; ask for clarification when necessary.

Learner Activity

Using the practice workbook, identify a dropdown, a Yes/No control, a date field, a text field, a numeric field, and an area that should not be edited.

Practice Task

Bring the foundation together
✓ Completed

You will work with a fictional business dataset. It is intentionally neutral so the practice can be reused across different PVA Academy courses.

Practice workbook: PVA_Spreadsheet_Basics_Practice.xlsx

Before You Start

Open the practice workbook and look around before changing anything. Identify the workbook, worksheets, headers, records, dropdowns, Yes/No controls, date fields, and areas that appear protected or non-editable.

Practice Tasks

  1. Locate information: Find customer ID C0148 in Customer Records and check its current Status.
  2. Update an existing record: Update C0148's Status to Completed.
  3. Add information: Find task T-1013 in Task Tracker and enter the requested Follow-up Date: October 2, 2026.
  4. Copy information: Find T-1013. Copy its Category value and paste it into the Practice Copy cell on the same row. Use Ctrl + C / Ctrl + V if supported.
  5. Sort the list: Sort Customer Records by Customer Name in alphabetical order. Keep each row's information together.
  6. Filter the list: Filter Customer Records so only Active customers are displayed. Review the results, then clear the filter.
  7. Use a dropdown: Change T-1016's Status to In Progress using the dropdown.
  8. Use a Yes/No control: Change T-1018's Follow-up Required field to Yes using the available dropdown/control.
  9. Find information outside the visible area: In Customer Records, locate the Notes column by scrolling horizontally. Find the note for C0162.
  10. Correct an accidental change: In the Undo Practice Area on Task Tracker, type TEST, then undo the change using Ctrl + Z or your application's Undo command.
  11. Save your work: Save the workbook using your application's normal save process. If supported, try Ctrl + S.
Accuracy check: Before considering the practice complete, ask: Did I edit the correct records? Did I change only what was requested? Did I accidentally overwrite anything?
